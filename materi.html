Pengertian Komputasi Awan

Komputasi awan (cloud computing) adalah model penyediaan layanan komputasi seperti server, penyimpanan data, database, jaringan, dan perangkat lunak yang diakses melalui internet. Pengguna tidak perlu membeli dan merawat perangkat keras sendiri, karena semuanya disediakan oleh penyedia layanan cloud. Biaya umumnya dihitung berdasarkan pemakaian, sehingga lebih fleksibel dan efisien.

Model Layanan

  • SaaS (Software as a Service): Layanan berupa aplikasi siap pakai yang diakses lewat internet, biasanya langsung dari browser. Pengguna tidak perlu menginstal atau mengurus server, cukup membuat akun lalu memakainya. Contohnya Google Drive, Gmail, dan Microsoft 365.
  • PaaS (Platform as a Service): Layanan berupa platform untuk membangun, menguji, dan menjalankan aplikasi tanpa harus mengatur server dan sistem operasinya. Pengembang cukup fokus pada kode dan aplikasinya. Contohnya Google App Engine, Heroku, dan GitHub Pages untuk menayangkan website statis.
  • IaaS (Infrastructure as a Service): Layanan berupa infrastruktur dasar seperti mesin virtual, penyimpanan, dan jaringan yang bisa disewa sesuai kebutuhan. Pengguna punya kontrol lebih besar, tetapi juga bertanggung jawab mengatur sistem operasi dan aplikasinya. Contohnya Amazon EC2, Google Compute Engine, dan Microsoft Azure Virtual Machines.

Manfaat Layanan Cloud

  • Hemat biaya awal: Pengguna tidak perlu membeli server dan perangkat keras mahal, karena cukup menyewa layanan dan membayar sesuai pemakaian.
  • Bisa diakses dari mana saja: Selama ada koneksi internet, data dan aplikasi dapat dibuka dari laptop, HP, atau perangkat lain tanpa terikat satu lokasi.
  • Mudah menyesuaikan kapasitas (skalabilitas): Kapasitas penyimpanan atau server bisa ditambah saat kebutuhan naik dan dikurangi saat kebutuhan turun.
  • Pemeliharaan dikelola penyedia: Pembaruan sistem, perbaikan, dan perawatan perangkat keras ditangani oleh penyedia layanan, sehingga pengguna bisa fokus pada pekerjaannya.
  • Ketersediaan tinggi: Layanan cloud berjalan di server yang terus aktif, sehingga website atau aplikasi tetap bisa diakses meski laptop pemiliknya dimatikan.
  • Kolaborasi lebih mudah: Banyak orang dapat mengakses dan mengerjakan berkas yang sama secara bersamaan, misalnya lewat Google Drive atau GitHub.
